- (direction) Coaching path selected; deliverable is only a compact implementation contract.
- (decision) Adopt Astro with TypeScript as a static-first site architecture, deployed on Vercel. Use local schema-validated content for the small, curated product catalog; avoid a database, CMS, accounts, and server rendering in v1.
- (decision) Defer the analytics provider and event implementation. The future solution must remain privacy-preserving and satisfy the PRD's aggregate measurement requirements without shaping the v1 core architecture.
- (decision) Use one local Astro build-time works content collection. Each work is one Markdown entry with schema-validated frontmatter for reusable metadata and a Markdown body for long product-specific content; all discovery, catalog, detail, and recommendation surfaces read this sole source of truth.
- (decision) Adopt Astro-first progressive enhancement with no React in v1. Native semantic HTML and CSS own presentation; small page-local TypeScript modules own only local interaction. The One-Shot Vibe Selection persists its state in the URL for history, reload, and shareability.
- (decision) Exclude React, Lenis, and Vanta from v1. CSS owns standard feedback and reveals; GSAP is an optional, page-local dependency only after a prototype proves that a small number of non-essential narrative sequences need it, with reduced-motion fallbacks.
- (decision) Use native CSS with CSS Custom Properties as the sole styling system; do not add Tailwind in v1. Maintain primitive, semantic, and component token layers for Saffron Myth Theatre, including responsive layout, component states, z-index layers, and reduced-motion rules.
- (decision) Version product images and self-hosted fonts in the repository. Each work content entry owns its asset references; Astro build-time image handling must reserve final dimensions and avoid inconsistent page-specific asset selection. Do not add external image CDNs or font providers in v1.
- (decision) Open DriveThruRPG, Ko-fi, and other external destinations in the same browser tab. External links visibly and accessibly identify their destination; browser Back returns visitors to the curated Tales by Xero context.
- (decision) Require lint and production build for every change; content schema errors and invalid internal work references fail the build. Before public launch, verify 375/768/1024/1440 px, keyboard navigation, and reduced-motion behavior on Home, Works, and a product detail page. Deploy only through Git-connected Vercel previews and main-to-production; do not use direct local production deploys.
- (version) Pin TypeScript 6.0.3 rather than latest 7.0.2 because @astrojs/check 0.9.10 supports TypeScript 5 or 6 only; require Node.js >=22.13.0 to satisfy Astro 7.3.5 and ESLint 10.11.0.
- (decision) Bind the normative works schema, One-Shot Vibe URL state /#one-shot-vibes, and a provider-neutral analytics event contract so separately built routes, content, and future analytics cannot drift.
- (decision) Bind product external URLs to DriveThruRPG, type-safe Discovery Route mappings, and src/data/home.ts as the sole Home route/featured/proof configuration. Bind Ephemera's standalone Abythera relation and Karrhold's included-with notice in content data.
- (decision) Future analytics must send all page views through the sanitized provider-neutral event adapter, disable incompatible automatic measurement, and meet documented no-cookie, no-identifier, no-advertising, no-retargeting, and IP/user-agent handling acceptance criteria before launch.
- (decision) Specify ableTestedProof as a typed statement with optional validated evidence reference, and bind the exact discriminated AnalyticsEvent union plus rack(event) signature for independent UI and adapter implementations.
